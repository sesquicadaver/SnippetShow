## D13 — Обрані / man-gate (затверджено 2026-11-14)

| # | Питання | Рішення |
|---|---------|---------|
| **D13.1** | First-run / «Встановлені» | Лише **назви** PATH-команд; без per-binary PM lookup / whatis на старті |
| **D13.2** | Режими | Radio: **Встановлені** \| **Обрані** \| **Пакети** |
| **D13.3** | Man | Лише для **обраних** (`is_favorite`); при «Обрати» — parse + запис `man_commands` |
| **D13.4** | Клік не-обраної у «Встановлені» | **Без man** — лише картка / дія «Обрати» (**так**) |
| **D13.5** | Зняття з Обраних | **Purge** `man_commands` + скинути `man_parsed` (**ні**, не лишати man у БД) |
| **D13.6** | «Обрати» на Пакетах | **Ні** — лише PATH / таблиця `programs` (**так**) |
| **D13.7** | UpdateIndex | Diff імен/версій; man-parse **лише** для favorites (version change / re-favorite) |
| **D13.8** | Категорії PM | Показувати **сирі** Section/Group з пакетного менеджера (не UA-словник-мапінг) |
| **D13.9** | Коли збагачувати category | **У фоні** після списку імен (bulk), не лише при «Обрати» |
| **D13.10** | «Без man» | Ортогональний **фільтр** (не окремий radio-режим) (**так**) |
| **D13.11** | Обрані без man | Дозволено: при absent man — попередження в wiki; `man_commands` не вигадувати |

D13.1–D13.11 повністю закривають модель SS-31 для імплементації.

## Примітки середовища

- На Ubuntu 24.04+ для збірки Wails потрібен tag **`webkit2_41`** (пакет `libwebkit2gtk-4.1-dev`), бо `webkit2gtk-4.0` більше не постачається. Обгортка: `build/build.sh`.
- Продукт **Linux-only**: каталоги `build/windows/` та `build/darwin/` не тримаємо в репо (ігнор у `.gitignore`, якщо Wails їх регенерує).
- Ubuntu smoke оркестратор: `scripts/ubuntu-dist-smoke.sh` + чекліст `build/dist-notes-ubuntu.md`.

## Модель загроз Run / Export (M7 / SAFE-02)

- Wails bindings (`RunCommand`, `RunScript`, `Export*`) довіряють локальному UI-процесу: параметр `confirmed: true` і довільний шлях експорту доступні з DevTools.
- Це **очікувана** модель для single-user desktop ELF (не мережевий сервіс): захист — діалог confirm у штатному UI + safety.Analyze перед стартом; sandbox / RPC auth поза MVP.
- Export у штатному UI йде через `SaveFileDialog` / `OpenFileDialog`; прямі `ExportScriptFile`/`ExportBackup(path)` лишаються для тестів і автоматизації.
